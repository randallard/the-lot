# 2026-10-31 (4): TypeScript 6.0.3

Ryan: *"start on TypeScript 6 for the-lot."* This is the first of the three steps left before
the-lot can claim provable-lite (ADR-1010).

## The change

`typescript` 5.9.3 → **6.0.3**, the newest 6.0.x (2026-04-16), the same as square-one. The
lockfile changes only typescript's own entry and the peer suffixes of the typescript-eslint
packages. typescript-eslint 8.65.0 accepts it (`>=4.8.4 <6.1.0`), and `pnpm install` reports no
unmet peers. **No source or tsconfig change was needed.**

Checked on 6.0.3, which covers everything CI runs:
- `tsc -b --force` exits 0.
- `pnpm lint`: 0 errors, the same 25 warnings.
- `vitest run`: 1,240 passed, 29 expected fail, 3 skipped.
- `pnpm build` passes.
- `pnpm audit`: 1 moderate, ignored (minimatch, as before).
- `pnpm audit signatures`: 471 verified.
- The licence allowlist passes.

## Two things found on the way

- **`api/` isn't in any tsconfig**, so neither `tsc -b` nor CI typechecks `npc-chat.ts` or
  `support.ts`; Vercel compiles them when it deploys. Checked by hand with the app's options and
  `--strict`, they're clean on both 5.9.3 and 6.0.3. Giving them a tsconfig reference is worth
  doing with the strictness work.
- **TS 6 refuses to compile files named on the command line while a tsconfig is present**
  (TS5112), unless you pass `--ignoreConfig`. This matters only for ad-hoc checks like the one
  above.
