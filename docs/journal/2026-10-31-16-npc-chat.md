# 2026-10-31 (16): api/npc-chat.ts

Ryan: *"start on api/npc-chat.ts."* This is the deployed serverless function behind NPC dialogue
(ADR-0006). Its 24 findings came from two untyped values, the request body (`await req.json()`)
and Anthropic's response (`await response.json()`), both read as `any`.

Both come from outside, so they're read as **`unknown`**, through two small helpers with no
casts: `field(v, key)` (a JSON value's own field, or `undefined`) and `str(v)` (the value if it's a
string). The function otherwise reads as it did.

- **Same behaviour**, including the error paths. With no `messages` and no `gameResults` it still
  ends in the 500, now by an explicit `TypeError` rather than a property read on `undefined`.
- **One deliberate tightening:** the model's `dialogue`, `defaultReply` and `defaultAction` are
  used only if they're strings, and otherwise fall back to the existing defaults. The tool schema
  says strings; before, whatever came back was passed on.
- **Nothing logged or stored**, so ADR-0006's commitment is untouched. The model id, the
  `max_tokens` and the forced `tool_choice` are unchanged; the Haiku question waits as decided.
